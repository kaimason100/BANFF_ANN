# Dataset Provenance And Preparation

The public repository includes the prepared MAT files used for the released
experiments in `Feedforward_network/data`. Their SHA-256 digests are recorded
in `data/SHA256SUMS`. These prepared copies are redistributed under their
respective upstream dataset licences, not under the repository's MIT licence.

Do not normalize the complete dataset before saving or replacing a file. Active
trainers fit all normalization statistics on the training split only. Tabular
predictors are subsequently divided by the square root of the predictor count.
MNIST-family images are standardized per pixel from the training images and
divided by `sqrt(784)`. These operations are performed by the trainers and were
not pre-applied to the supplied dataset files.

## Missing And Non-finite Values

All active tabular loaders include a defensive `~isfinite` replacement. In the
supplied files this replacement changes only `car_dataset.mat`:

- the stored matrix contains 432 NaNs in column 3, representing the legitimate
  `doors = 5more` category;
- it contains 576 NaNs in column 4, representing the legitimate
  `persons = more` category;
- the loaders replace these NaNs with zero in memory before splitting or
  standardization. Zero is not used by another category in either column, so it
  remains a distinct category code. The MAT file itself is not overwritten.

The original Mushroom data use `?` for 2,480 unknown `stalk-root` entries. In
the supplied `mushroom_dataset.mat`, these entries are deliberately retained as
the fifth categorical code in that predictor rather than represented by NaN or
zero. The supplied Mushroom matrix therefore contains neither NaNs nor zeros.

The supplied Abalone, Breast Cancer, Toyota and MNIST-family MAT files contain
no NaN or infinite values. Their stored zeros are data values, class labels or
image background pixels, rather than values introduced by the runtime
non-finite-value replacement. Consequently, the same defensive statements are
no-ops for those files.

## Tabular Classification

### Breast Cancer Wisconsin Diagnostic

Source: <https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic>
Dataset DOI: <https://doi.org/10.24432/C5DW2B>

Save `data/breast_cancer_dataset.mat` with a variable named `data`. Supported
layouts are:

- table or cell array: identifier in column 1, diagnosis label in column 2,
  and the 30 numeric features in columns 3:32;
- numeric matrix: placeholder/identifier in column 1, numeric class code in
  column 2, and numeric features in columns 3:end;
- struct: `data.features` is `N x 30` and `data.labels` is `N x 1`.

For the raw UCI/WDBC file, retain the identifier in column 1. The current
loader deliberately reads labels from column 2 and features from column 3
onward. Removing the identifier without inserting a placeholder shifts every
column and produces the wrong task.

### Car Evaluation

Source: <https://archive.ics.uci.edu/dataset/19/car+evaluation>
Dataset DOI: <https://doi.org/10.24432/C5JP48>

Save `data/car_dataset.mat` containing an `N x 7` numeric matrix named `data`:

- columns 1:6: encoded buying, maintenance, doors, persons, luggage boot, and
  safety predictors;
- column 7: encoded acceptability class.

Convert each raw categorical column with one fixed mapping. Record and reuse
that mapping; independently applying `grp2idx` to subsets can change the code
assigned to a category.

The supplied publication dataset preserves the historical preparation used for
the reported experiments: `5more` in the doors column and `more` in the persons
column are stored as NaN and converted to the reserved code zero by every active
training and testing loader. These are category encodings, not missing values.

### Mushroom

Source: <https://archive.ics.uci.edu/dataset/73/mushroom>
Dataset DOI: <https://doi.org/10.24432/C5959T>

Save `data/mushroom_dataset.mat` containing a numeric matrix named `data`:

- column 1: encoded edible/poisonous class;
- columns 2:end: consistently encoded categorical predictors.

Use one mapping per original column and apply it before the trainer creates its
split. The original `?` entries for unknown stalk root are a distinct category;
the supplied matrix encodes that category as `5`. They are not imputed from
training, validation, or test observations.

## Regression

### Abalone

Source: <https://archive.ics.uci.edu/dataset/1/abalone>
Dataset DOI: <https://doi.org/10.24432/C55C7W>

Save `data/abalone_dataset.mat` containing a numeric matrix named `data`.
For the publication task it has eight predictor columns followed by the target:

1. numeric code for sex;
2. length;
3. diameter;
4. height;
5. whole weight;
6. shucked weight;
7. viscera weight;
8. shell weight;
9. rings, the predicted target.

The predicted variable is therefore the observed number of rings, commonly
used as an age proxy. Use one numeric sex column for the eight-input
publication architecture; one-hot encoding changes the input dimension and is
not the same released experiment.

### Toyota Used-Car Price

Source: <https://www.kaggle.com/datasets/adityadesai13/used-car-dataset-ford-and-mercedes>

Use the Toyota subset (`toyota.csv`) from the 100,000 UK Used Car dataset. Its
raw fields are model, year, price, transmission, mileage, fuel type, tax, mpg,
and engine size. Encode categorical predictors consistently, then save
`data/toyota_dataset.mat` with a numeric matrix named `data` arranged so that:

- column 3 is `price`, the predicted target;
- columns 1, 2, and 4:end are the predictors.

The loader uses exactly `y = data(:,3)` and
`X = data(:,[1,2,4:end])`. Preserve the category-to-number mappings used to
prepare the file. A different mapping remains mathematically usable but is not
an exact reproduction of the deposited experiment data.

## MNIST-Family Images

Sources:

- MNIST: <http://yann.lecun.com/exdb/mnist/>
- Fashion-MNIST: <https://github.com/zalandoresearch/fashion-mnist>
- Kuzushiji-MNIST: <https://github.com/rois-codh/kmnist>
- Afro-MNIST: <https://github.com/Daniel-Wu/AfroMNIST>

Prepare these filenames:

```text
mnist.mat
mnist_fashion.mat
kmnist.mat
afro_mnist_ethiopic.mat
afro_mnist_nko.mat
afro_mnist_osmanya.mat
afro_mnist_vai.mat
```

Each file must contain separate `training` and `test` variables. The most
portable structure is:

```matlab
training.images   % 28 x 28 x 1 x Ntrain, 28 x 28 x Ntrain, or 784 x Ntrain
training.labels   % Ntrain x 1
test.images       % corresponding held-out test images
test.labels       % corresponding held-out test labels
```

Images must be grayscale 28-by-28 arrays and each task must contain ten label
classes. Do not merge the official test set into `training`. The trainer creates
a fixed train/validation split from `training` and reserves `test` for final
evaluation.

Example save operation:

```matlab
training.images = XTrain;
training.labels = YTrain;
test.images = XTest;
test.labels = YTest;
save("data/mnist.mat", "training", "test", "-v7.3")
```

## Motor Control

No source MAT file is required before training. The active motor-control script
generates 250 supervised LQR episodes, makes an episode-level training and
validation split, and generates 100 separate held-out targets. It writes
`data/LQR_SUPERVISED_EPISODES_20251002_172744.mat` as a generated compatibility
artifact for plotting and inspection. Do not substitute rows from that file
into the held-out closed-loop test.

## Dynamical Systems

The supplied `examples/dynamical_systems/dynamics_list.xlsx` is part of the
source release. The active code accesses these columns by position:

- column 1: system name;
- column 2: state dimension;
- columns 4:6: reference initial condition.

The active task rows are `[5, 34, 39, 41, 47, 32, 8, 9, 25]`, corresponding to
Lorenz, MO0, MO5, MO7, MO13, Rikitake, SprottB, SprottC, and SprottS. Do not
reorder spreadsheet rows unless the task-row lists are updated at the same
time.

## Integrity Checks

Before training, verify each MAT file contains the expected top-level variable:

```matlab
whos("-file", "data/abalone_dataset.mat")
whos("-file", "data/mnist.mat")
```

After loading a tabular matrix, check row count, column count, expected
non-finite encodings, and target position. The Car matrix is the documented
exception to an otherwise finite-value check. Do not create
train/validation/test splits externally; the scripts use fixed split seeds and
save the indices with every network.

The test scripts fail if split metadata overlaps, if saved training statistics
do not match the training rows, or if an MNIST-family network does not use the
official held-out test split.
